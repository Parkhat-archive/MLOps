Голос

Голоса Piper — нейросеть, работает прямо в телефоне и без интернета. Один раз скачивается модель (~60 МБ на голос, лучше по Wi-Fi).
Системные голоса лучше: Android → Настройки → Синтез речи → Google → Установка голосовых данных → Русский.

Книга на GitHub

Токен: github.com → Fine-grained token → Repository access: «Only select repositories» → репозиторий книги → Permissions → Contents: «Read and write». Используйте приватный репозиторий.

Диагностика…
Текст сохранится ровно так, как написан. Пустая строка между абзацами создаёт новый абзац.

Как пользоваться

Нажмите на предложение — чтение начнётся с него. Кнопки внизу работают с выделенным предложением:
🎤 Правка — скажите новый вариант («пусть будет …»; «удали» — удалить).
➕ Фраза — вставить сказанное после предложения. ¶ Абзац — новым абзацем.
📝 Заметка — комментарий, текст не меняется. 🚩 Флажок — отметить, чтобы вернуться.
Всё сохраняется на телефоне автоматически; «Сохранить» создаёт версию (и отправляет в GitHub для глав оттуда).
